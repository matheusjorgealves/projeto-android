# História do Mascote do Android

Este é um projeto web focado em design e conteúdo, que conta a história e as curiosidades por trás da criação do famoso mascote do sistema operacional **Android** (o Bugdroid), além de listar as clássicas versões "adocicadas" do sistema.

## 🔗 Link para Acesso

Você pode visualizar o site publicado clicando no link abaixo:

👉 [Acessar o Projeto Android](https://matheusjorgealves.github.io/projeto-android/)

## 📝 Conteúdo do Site

O site apresenta artigos explicativos sobre:
* A primeira e bizarra versão do mascote (os *Dandroids*)
* Como a ilustradora Irina Blok se inspirou em placas de banheiro para criar o *Bugdroid*
* A linha do tempo das versões do Android nomeadas em homenagem a doces (do Cupcake ao Pie)

## 🛠️ Tecnologias e Conceitos Praticados

* **HTML5:** Estruturação semântica do conteúdo (artigos, seções, listas)
* **CSS3:** Estilização, tipografia e elementos visuais adaptados ao tema de tecnologia
* **Design Responsivo:** Layout adaptável para diferentes tamanhos de tela
